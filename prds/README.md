# PRDs

Product Requirements Documents for significant features and changes.

- Active PRDs: `prds/NNN-slug.md`
- Completed PRDs: `prds/done/NNN-slug.md`
- Each PRD has a GitHub issue with label `prd`
- The issue is a stub; the markdown file is the source of truth

Use `/prd new` from Claude Code to create a new PRD, or see the templates repo at `~/repos/workflow/llm-coding-workflow/templates/prd/`.
